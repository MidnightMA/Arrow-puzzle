# بازی پازل جهت‌ها (Arrow Puzzle) | مینی‌اپ ایتا

یک بازی معمایی فکری، جذاب و تعاملی توسعه‌داده‌شده به صورت **Eitaa Mini App** با استفاده از **Vanilla HTML/CSS/JavaScript** و بدون هیچ‌گونه فریم‌ورک سنگین، متصل به **Supabase Edge Functions** و پایگاه‌داده **PostgreSQL** و آماده برای استقرار رایگان روی **GitHub Pages**.

---

## ۱. ویژگی‌ها و مشخصات بازی

- **گیم‌پلی معمایی مبتنی بر استراتژی:** کاربر باید با کلیک یا لمس فلش‌ها، صفحه را خلوت کند. هر فلش فقط در صورتی آزاد می‌شود که در جهت حرکت خود تا لبه صفحه با فلش دیگری برخورد نکند.
- **تضمین ۱۰۰٪ حل‌پذیری (Solvability Guarantee):** الگوریتم شبیه‌ساز قبل از تحویل هر مرحله، حل‌پذیری آن را بررسی می‌کند؛ بنابراین هیچ مرحله غیرممکن یا بن‌بست اولیه‌ای وجود ندارد.
- **طراحی بصری چشم‌نواز و مدرن (Modern Dark Arcade):** انیمیشن‌های روان پرواز فلش، لرزش بازخورد هنگام مسدود بودن، جلوه نورانی راهنما، پشتیبانی کامل از RTL و تایپوگرافی چشم‌نواز وزیرمتن (Vazirmatn).
- **صداگذاری اختصاصی تحت وب (Web Audio API):** افکت‌های صوتی حرکات، خطاها، راهنما و پیروزی به صورت کاملاً برنامه‌نویسی‌شده و بدون نیاز به دانلود فایل صوتی حجیم خارجی با قابلیت قطع و وصل صدا.
- **سیستم بازگشت حرکت (Undo) و راهنما (Hint):** امکان بازگرداندن حرکت‌های قبلی یا درخواست نمایش یکی از فلش‌های آزاد.
- **یکپارچه‌سازی کامل با Eitaa SDK:** استفاده از اسکریپت رسمی ایتا (`eitaa-web-app.js`)، بازخوردهای لرزشی لمسی (Haptic Feedback)، هماهنگی با دکمه بازگشت (BackButton) و تم پیام‌رسان.
- **امنیت و اعتبارسنجی سمت سرور (Supabase Edge Functions):** اعتبارسنجی امضای امنیتی `initData` ایتا با استاندارد HMAC-SHA256، جلوگیری از تقلب در ثبت امتیازات و جدول برترین‌ها (Leaderboard).

## ۳. راهنمای گام‌به‌گام راه‌اندازی و استقرار

### مرحله ۱: پیش‌نیازها
1. حساب کاربری در [GitHub](https://github.com) برای میزبانی فرانت‌اند روی GitHub Pages.
2. حساب کاربری در [Supabase](https://supabase.com) برای دیتابیس و توابع ابری (Edge Functions).
3. نصب ابزار [Supabase CLI](https://supabase.com/docs/guides/cli) روی سیستم خود (اختیاری برای تست محلی یا دیپلوی مستقیم).
4. دریافت توکن بات ایتا از طریق بات‌ساز ایتا (@BotFather در ایتا) برای مینی‌اپ.

---

### مرحله ۲: راه‌اندازی دیتابیس در Supabase
1. وارد پنل کاربری Supabase شوید و یک پروژه جدید به نام `arrow-puzzle` ایجاد کنید.
2. از منوی سمت چپ به بخش **SQL Editor** بروید.
3. محتویات فایل `supabase/migrations/20260917000000_initial_schema.sql` را در ویرایشگر SQL کپی کرده و دکمه **Run** را بزنید.
   - این اسکریپت جدول‌های `players` و `scores`، ایندکس‌های رتبه‌بندی و قوانین امنیتی (RLS) را می‌سازد.
4. (اختیاری) محتویات فایل `supabase/seed.sql` را نیز اجرا کنید تا رتبه‌بندی اولیه پر شود.

---

### مرحله ۳: تنظیم متغیرهای امنیتی (Secrets) در Supabase
در داشبورد Supabase، به بخش **Project Settings > Edge Functions** یا از طریق ترمینال CLI بروید و متغیرهای زیر را تنظیم کنید:

```bash
# با استفاده از CLI
supabase secrets set EITAA_BOT_TOKEN="توکن_دریافتی_از_بات_ایتا"
supabase secrets set ALLOWED_ORIGIN="https://yourusername.github.io"
```

> **نکته امنیتی بسیار مهم:** توکن بات ایتا و کلید Service Role هرگز نباید در فایل‌های کلاینت (`index.html` یا پوشه `js/`) قرار بگیرند. تمام این اطلاعات صرفاً در حافظه امن Edge Function نگهداری می‌شوند.

---

### مرحله ۴: استقرار توابع سمت سرور (Edge Functions)
با استفاده از ترمینال در پوشه پروژه:

```bash
# ورود به حساب کاربری
supabase login

# لینک کردن پروژه
supabase link --project-ref <شناسه-پروژه-شما>

# انتشار تابع api
supabase functions deploy api --no-verify-jwt
```

پس از انتشار، آدرس تابع شما به شکل زیر خواهد بود:
`https://<project-ref>.supabase.co/functions/v1/api`

---

### مرحله ۵: تنظیم آدرس API در فرانت‌اند
فایل `index.html` را باز کنید و در تگ `<script>` تنظیمات، آدرس تابع منتشرشده را قرار دهید:

```html
<script>
  window.ARROW_PUZZLE_CONFIG = {
    apiBaseUrl: "https://<your-project-ref>.supabase.co/functions/v1/api"
  };
</script>
```

*(در صورت خالی بودن این متغیر، بازی به صورت آفلاین و خودکار با ذخیره‌سازی محلی روی دستگاه کاربر کار خواهد کرد).*

---

### مرحله ۶: انتشار روی GitHub Pages
1. تغییرات را به مخزن گیت خود پوش کنید:
   ```bash
   git add .
   git commit -m "Complete Arrow Puzzle Eitaa Mini App"
   git push origin main
   ```
2. به صفحه مخزن در گیت‌هاب بروید و وارد تب **Settings > Pages** شوید.
3. در بخش **Build and deployment**، گزینه **Source** را روی **Deploy from a branch** بگذارید.
4. شاخه `main` و مسیر `/ (root)` را انتخاب کرده و دکمه **Save** را بزنید.
5. پس از ۲ الی ۳ دقیقه، آدرس اختصاصی شما آماده می‌شود (مثلاً `https://yourusername.github.io/Arrow-puzzle/`).

---

### مرحله ۷: اتصال به پیام‌رسان ایتا به عنوان مینی‌اپ
1. در پیام‌رسان ایتا به بات‌ساز رسمی ایتا مراجعه کنید.
2. گزینه ثبت وب‌اپلیکیشن (Mini App) را برای بات خود انتخاب کنید.
3. آدرس دامنه گیت‌هاب پیجز خود (مثلاً `https://yourusername.github.io/Arrow-puzzle/`) را به عنوان URL وب‌اپلیکیشن وارد نمایید.
4. مینی‌اپ شما آماده است و کاربران می‌توانند آن را مستقیماً داخل ایتا باز کرده و رقابت کنند!

## ۴. اجرای محلی و تست (Local Development)

برای اجرای بازی روی سیستم خود، می‌توانید از هر وب‌سرور سبک لوکال استفاده کنید:

```bash
# با پایتون
python3 -m http.server 8080

# یا با ابزار serve در صورت نصب بودن Node
npx serve .
```

سپس مرورگر خود را باز کرده و به آدرس `http://localhost:8080` بروید.
برای اجرای تست‌های واحد الگوریتم تولید و حل پازل:
```bash
node tests/puzzle-check.js
```

## ۵. راهنمای رفع مشکلات متداول (Troubleshooting)

1. **خطای CORS در کنسول مرورگر:**
   - مطمئن شوید آدرس دامنه شما در متغیر `ALLOWED_ORIGIN` در Supabase تنظیم شده باشد یا منبع درخواست با دامنه‌های مجاز هماهنگ باشد.
2. **عدم لود تم یا هپتیک در تست مرورگر عادی:**
   - کامپوننت `js/eitaa.js` دارای حالت بازگشت خودکار (Fallback) است؛ هنگامی که بازی بیرون از پیام‌رسان ایتا اجرا می‌شود، از قابلیت‌های ویبره استاندارد مرورگر استفاده می‌کند و اروری ایجاد نمی‌کند.
3. **عدم نمایش صحیح فونت فارسی در حالت آفلاین:**
   - فونت وزیرمتن از شبکه پرسرعت Google Fonts بارگذاری می‌شود و استک فونت‌های پیش‌فرض سیستم (`system-ui, Tahoma`) به عنوان جایگزین در استایل تعبیه شده است.
